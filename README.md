# Gerenciador de Tarefas

Projeto desenvolvido em JavaScript com Node.js para gerenciamento de tarefas pelo terminal.

## Funcionalidades

- Adicionar novas tarefas
- Listar tarefas cadastradas
- Marcar tarefas como concluídas
- Remover tarefas
- Armazenar tarefas em arquivo JSON

## Tecnologias utilizadas

- JavaScript
- Node.js
- JSON

## Estrutura do projeto

- `app.js` — código principal da aplicação
- `tarefas.json` — arquivo de armazenamento das tarefas

## Objetivo

Projeto prático desenvolvido para exercitar lógica de programação, manipulação de arquivos e desenvolvimento com JavaScript e Node.js.
